# Meeting Minutes Generator

Standalone, front-end-only meeting minutes tool for construction, engineering and business meetings.

- Single file app: open `index.html` in a browser (no server, no backend)
- Data stays in the browser (localStorage); backup/restore via JSON
- Quick Notes to formal minutes, action item register, templates
- Word (.docx) and PDF (print) export, individual and batch
- Delete records and see remaining storage

## Run locally
Open `index.html`, or serve the folder: `python3 -m http.server 8000`

## Publish with GitHub Pages
Settings > Pages > Deploy from branch `main` / root.
